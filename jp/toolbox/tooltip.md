# ツールチップの概要

App Builder の**ツールチップ** コンポーネントを使用すると、アプリケーション内のターゲット要素にユーザーがカーソルを合わせるかフォーカスを当てたときに、コンテキスト ヘルプや補足情報を表示できます。ツールチップは**プロパティ** パネルを通じてビジュアルに設定でき、トリガーとコンテンツはすべてコードを記述せずにカスタマイズできます。

ツールチップは基盤となる [Ignite UI ツールチップ](https://jp.infragistics.com/products/ignite-ui-angular/angular/components/tooltip) コンポーネントを使用し、Angular、React、Blazor、Web Components 向けのクリーンなフレームワーク固有のコードを生成します。

## 主な機能

### コンポーネントへのツールチップの追加

ツールチップは、ターゲット コンポーネントの**プロパティ** パネルから直接有効化します。ツールチップを追加するには:

1. **デザイン キャンバス**でターゲット コンポーネントを選択します。
2. **プロパティ** パネルで「**ツールチップ**」セクションまでスクロールします。
3. **ツールチップを有効にする** トグルをオンにします。
4. 表示される **ツールチップを編集** リンクをクリックしてツールチップを開き、プロパティ (ターゲット、モード、表示遅延、非表示遅延、矢印) を設定します。


### ツールチップ コンテンツ

ツールチップのコンテンツを**変数**や接続されたデータ ソースの**データ フィールド**にバインドすることで、実行時に動的でコンテキストに応じたヒントを提供できます。


### 表示 / 非表示の遅延

以下を設定してツールチップの応答性を制御します:

- **表示遅延** — ユーザーがターゲットにカーソルを合わせてからツールチップが表示されるまでの時間 (ミリ秒)。デフォルト値は **300 ms**。
- **非表示遅延** — カーソルがターゲットから離れてからツールチップが消えるまでの時間 (ミリ秒)。デフォルト値は **0 ms**。

これらの遅延はユーザービリティを向上させ、ユーザーが複数の要素間でカーソルを素早く移動する際のツールチップのチラツきを防ぎます。

### モード

**モード** プロパティはツールチップの閉じ方を制御します:

- **デフォルト** — ツールチップはホバー/フォーカス時に表示され、カーソルまたはフォーカスがターゲットから離れると自動的に消えます。
- **スティッキー** — ツールチップはユーザーが明示的に閉じるまで表示されたままになります。

### 矢印

**矢印** インジケーターの表示/非表示を切り替えます。有効の場合、小さな矢印がツールチップからターゲット要素を指し示し、ツールチップとターゲット間の関連を視覚的に明確にします。

### ツールチップ トリガー

デフォルトでは、ツールチップは**ホバー** (マウス) と**フォーカス** (キーボード) でトリガーされます。この二重動作により、WCAG ガイドラインへのアクセシビリティ準拠が確保されます。

## サポートされているプロパティ

| プロパティ      | 説明                                                          |
|----------------|--------------------------------------------------------------|
| ターゲット      | ツールチップが関連付けられているコンポーネント                 |
| モード            | ツールチップの閉じ方: **デフォルト** (自動) または **スティッキー** (手動) |
| 表示遅延        | ツールチップが表示されるまでの遅延 (ミリ秒)。デフォルト値: 300      |
| 非表示遅延      | ツールチップが非表示になるまでの遅延 (ミリ秒)。デフォルト値: 0        |
| 矢印            | 方向指示矢印インジケーターの表示/非表示を切り替える          |

## アクセシビリティ

ツールチップ コンポーネントはアクセシビリティを考慮して構築されています:

- ターゲット要素は、ツールチップ コンテンツにリンクする `aria-describedby` を受け取ります。
- ツールチップはフォーカス イベントを介してキーボード アクセスが可能です。
- 適切な ARIA ロールによるスクリーン リーダー サポートが含まれています。

## コードの生成

App Builder はビジュアル設定に基づいてフレームワーク固有のツールチップ コードを生成します:

- **Angular**: Ignite UI for Angular の `igxTooltip` および `igxTooltipTarget` ディレクティブを使用します。
- **React**: Ignite UI for React の `IgrTooltip` コンポーネントを使用します。
- **Blazor**: Ignite UI for Blazor の `IgbTooltip` を使用します。
- **Web Components**: Ignite UI for Web Components の `igc-tooltip` を使用します。

> [!NOTE]
> 変数またはデータ フィールドにバインドされたツールチップのコンテンツは、各フレームワーク固有の動的バインディングとして生成されたコードに反映されます。

## 既知の問題と制限事項

- **ネストされたツールチップ**は使用できません。
- **繰り返しツールチップ**はすべてのプラットフォームでコードが生成されますが、正しく動作するのは **Angular** のみです。
- **繰り返し Select アイテム内のツールチップ**: Select アイテム内のツールチップは、セレクト アイテムをラップする `ng-container` に `ngProjectAs` 属性を追加しない限り、Angular では機能しません。以下に例を示します:

```html
<igx-select type="border" class="user-input">
  @for (item of northwindCategories; track item) {
    <ng-container ngProjectAs="igx-select-item">
      <igx-select-item value="Option" #selectItem [igxTooltipTarget]="tooltip4" [showDelay]="300" [hideDelay]="0">
        {{ item.name }}
      </igx-select-item>
      <div #tooltip4="tooltip" igxTooltip>
        <div class="column-layout group_1">
          <p class="ig-typography__body-2 text">
            {{ item.description }}
          </p>
        </div>
      </div>
    </ng-container>
  }
  <label igxLabel>Label/Placeholder</label>
</igx-select>
```
